PART A PHASE 1: Default Service Implementations (17 files)
----------------------------------------------------------------------

Stock implementations of the abstract service interfaces. Prefixed with
"Default" (not "Test") to signal they are reusable, not demo-specific.
Refer to the abstract interfaces in tom_forge_ui/lib/src/services/ and
tom_forge_ui/lib/src/shell/ for the exact method signatures.

A1. Create src/defaults/memory_file_system.dart
    Implements ForgeFileSystem backed by Map<String, List<int>>.
    Constructor takes Map<String, String> seed (path -> content).
    ForgeFileSystem references dart:io types (FileStat, FileSystemEntity,
    FileSystemEvent). Create MemoryFileStat and MemoryFileEntry shims.
    stat() returns MemoryFileStat. list() returns MemoryFileEntry list.
    watch() returns Stream.empty(). The key methods are
    read/readBytes/write/save/delete/exists.
    applyWorkspaceEdit() applies edits to the in-memory map.
    Fires onDidChange/onDidSave streams on mutations.
    Export MemoryFileStat and MemoryFileEntry for consumers.

A2. Create src/defaults/default_system_state.dart
    Implements ForgeSystemState. ValueNotifier for mutable state,
    StreamController.broadcast() for all event streams.
    Sensible defaults (empty lists, null). Exposes update methods
    (setActiveEditor, setFocusedComponent, updateDiagnostics, etc.)
    that are not on the abstract interface -- for internal shell use.

A3. Create src/defaults/default_layout_controller.dart
    Implements ForgeLayoutController. Panel visibility/size via
    ValueNotifiers. openFile(uri) resolves editor via ModuleRegistry,
    loads content from ForgeFileSystem, creates controller + adapter.
    Needs: DefaultSystemState, ForgeFileSystem, ForgeModuleRegistry.
    Editor creation pattern for openFile():
      .md/.markdown -> MdEditorController + ForgeMdEditor
      .dart -> DartCodeController + ForgeDartEditor
      .yaml/.yml -> YamlEditorController + ForgeYamlEditor
    closeEditor flow: dirty check, remove tab, dispose, update state.
    Defaults: left=250px, right=220px, bottom=180px, 1 middle panel.

A4. Create src/defaults/default_module_registry.dart
    Implements ForgeModuleRegistry. Map<Type, ForgeModule> backing.
    register() adds, get<T>() looks up, allModules returns values.

A5. Create src/defaults/default_status_bar_controller.dart
    Implements ForgeStatusBarController. items getter aggregates
    StatusBarItems from all registered modules, sorted by priority.

A6. Create src/defaults/default_diagnostic_manager.dart
    Implements ForgeDiagnosticManager. DefaultDiagnosticCollection
    stores Map<Uri, List<ForgeDiagnostic>>. all getter flattens.
    forUri() filters. Notifies listeners on changes.

A7. Create src/defaults/default_output_manager.dart
    Implements ForgeOutputChannelManager. DefaultOutputChannel stores
    lines in List<String>, exposes ValueNotifier for UI rebuild.

A8. Create src/defaults/default_search_manager.dart
    Implements ForgeSearchManager. Constructor takes ForgeFileSystem.
    search() reads all files, line-by-line matching. Supports
    isRegExp, isCaseSensitive, isWordMatch. searchStream() yields
    per-file results.

A9. Create src/defaults/default_notification_manager.dart
    Implements ForgeNotificationManager. Internal
    ValueNotifier<List<NotificationItem>> where NotificationItem has
    message, severity, actions, Completer for response.
    Auto-dismiss logic (4s default).

A10. Create src/defaults/default_outline_manager.dart
     Implements ForgeOutlineManager. Stores registered providers.
     Queries providers when active editor changes, exposes items
     via ValueNotifier<List<ForgeOutlineItem>>.

A11. Create src/defaults/default_dialog_manager.dart
     Implements ForgeDialogManager with Flutter dialogs.
     showQuickPick -> SimpleDialog with selectable items.
     showInputBox -> AlertDialog with TextField.
     showOpenDialog/showSaveDialog -> simplified picker.
     Needs GlobalKey<NavigatorState> for showing dialogs.

A12. Create src/defaults/default_clipboard.dart
     Implements ForgeClipboard. Wraps Flutter
     Clipboard.getData/setData from services.dart.

A13. Create src/defaults/default_config_manager.dart
     Implements ForgeConfigManager. Holds ForgeConfig.
     update() applies mutation and fires onDidChange.
     resetToDefaults() restores default.

A14. Create src/defaults/default_progress_manager.dart
     Implements ForgeProgressManager. withProgress() runs task
     while exposing state via ValueNotifier.
     DefaultProgressReporter updates message/increment.

A15. Create src/defaults/default_undo_manager.dart
     Implements ForgeUndoManager. Simple undo/redo stack.
     ValueNotifier<bool> for canUndo/canRedo.

A16. Create src/defaults/stub_services.dart
     Minimal no-op implementations for low-priority services:
     - StubTerminalManager (no-op terminal)
     - InMemorySecretStorage (Map<String, String>)
     - DefaultEnvironment (takes appName, openExternal logs)
     - StubFileDecorationManager (no-op disposable)
     - StubVirtualDocumentManager (no-op disposable)
     - DefaultShortcutManager (tracks bindings, rebind, reset)
     - InMemoryModuleStorage (Map<String, Map<String, Object>>)

A17. Create src/defaults/default_shell_api.dart
     Implements ForgeShellApi aggregating all services.
     Constructor takes all 21 service/shell instances.
     Also provide a convenience factory:

       factory DefaultForgeShellApi.withDefaults({
         required Map<String, String> fileSystemSeed,
         required String appName,
         required GlobalKey<NavigatorState> navigatorKey,
       })

     Creates all default services internally and wires them.

FUTURE CONSIDERATION: tom_forge_core restructuring
========================================================================

Several service interfaces in tom_forge_ui are pure Dart (no Flutter
imports) and could move to tom_forge_core for non-Flutter consumers:

  Pure Dart -- movable to tom_forge_core:
    ForgeFileSystem          (dart:io + tom_forge_core only)
    ForgeClipboard           (no imports)
    ForgeDiagnosticManager   (tom_forge_core types only)
    ForgeOutputChannelManager (no imports)
    ForgeSearchManager       (tom_forge_core types only)
    ForgeNotificationManager (no imports)
    ForgeProgressManager     (tom_forge_core types only)
    ForgeSecretStorage       (tom_forge_core types only)
    ForgeEnvironment         (no imports)
    ForgeTerminalManager     (no imports)
    ForgeVirtualDocumentManager (ForgeDisposable only)
    ForgeConfigManager       (tom_forge_core + ForgeConfig model)
    ForgeDisposable          (no imports)

  Flutter-dependent -- must stay in tom_forge_ui:
    ForgeUndoManager          (ValueListenable from flutter/foundation)
    ForgeFileDecorationManager (Color from flutter/widgets)
    ForgeShortcutManager      (LogicalKeyboardKey via ForgeShortcutBinding)
    ForgeOutlineManager       (ForgeEditor depends on Widget)
    ForgeModuleStorage        (ForgeModule depends on Widget)
    ForgeDialogManager        (ForgeQuickPickItem uses IconData indirectly)

  Model classes needing Flutter:
    ForgeApplication  (IconData)
    ForgeAction       (IconData)
    StatusBarItem     (ValueListenable, IconData)

This is a separate future task. When ready:
  1. Move pure-Dart interfaces to tom_forge_core
  2. Move pure-Dart default implementations alongside
  3. Have tom_forge_ui re-export from tom_forge_core for compatibility
  4. Keep Flutter-dependent types in tom_forge_ui
