# tom_specs_editor

The **TomSpecs Editor** — a Tom Forge desktop app for authoring
DocSpecs / CodeSpecs / Implementation specifications.

It launches a Tom Forge shell hosting:

- a model-driven **document editor** over the bundled spec model,
- the ported **structure browser** + structural review,
- an embedded **Claude Code agent** (chat composer, prompt queue, prompt
  trail) built on the shared agent UI.

## Architecture

| Layer | Package |
| --- | --- |
| Forge shell (launcher, panels, modules) | `tom_forge_ui`, `tom_forge_core` |
| Reusable agent/chat **UI** | `tom_forge_agentic` |
| Agent provider/model API + placeholder engine (no UI) | `tom_core_agentic` |
| Spec object model + bundled `spec_model.json` | `tom_specs_model` / `tom_specs_clitool` (build-time) |

## Status

Scaffold (Stage B, step 8 of the editor implementation plan). The app launches
a **blank Forge shell** with the bundled `assets/spec_model.json` model graph
(generated by `tom_specs_clitool/bin/model_json.dart`). The custom module set
and the 4-region DocSpecs layout arrive in step 9; the DocSpecs schema assets
in step 23.
